# 🌐 Personal Website & Portfolio

A modern, high-performance personal portfolio and interactive showcase built with **React**, **TypeScript**, **Vite**, and **Tailwind CSS**. It features interactive project demos, custom audio playback, a contact form powered by Formspree, and automated deployment via **GitLab CI/CD**.

✨ **Live Demo:** [tyler-waltner-group.gitlab.io/personal-website](https://tyler-waltner-group.gitlab.io/personal-website/)

---

## 🚀 Featured Projects

* **NASA NeoW API Visualizer**: A 3D web application fetching and rendering real-time near-Earth asteroid data from NASA's NeoWs API. Bridges declarative React with imperative WebGL using `useRef`, custom caching, and garbage collection.
* **Dynamic CLI Minibatch MLP**: A custom Multi-Layer Perceptron built from scratch without popular ML frameworks to classify the FashionMNIST dataset, featuring stochastic gradient descent (SGD), He weight initialization, and dynamic CLI hyperparameter configuration.
* **Map Routing & Pathfinding Visualizer**: A geographic routing application utilizing Dijkstra's algorithm and a custom PriorityQueue with custom graph data structures and Haversine distance calculations.
* **2D Gravity Simulation Engine**: An interactive 2D physics simulation modeling N-body gravitational interactions with custom vector mathematics and Newtonian mechanics for real-time particle trajectories and collision dynamics.
